\section*{Setup}
10 $\times$ 10 grid: $\gamma \in \{0.1, 0.3, 1, 3, 10, 30, 100, 300, 1000, 3000\}$,
$\tau \in \{0.001, 0.005, 0.01, 0.05, 0.1, 0.3, 0.5, 0.7, 0.85, 1.0\}$.
100 cells, Method C v2 additive Bayesian-symmetric monotone ansatz fit
against the Lin-CDF R4 operator. ~2 min total. Chain warm-start across
$\tau$ within each $\gamma$ column.

\section{Structural-deficit residual $|F|_\infty$}

\begin{center}
\includegraphics[width=\linewidth]{fig1_F.png}
\end{center}

This is the residual after fitting the best 5-parameter additive monotone
ansatz. It measures \textbf{how much the equilibrium needs cross-signal
joint structure beyond the additive form} (= the true "deficit").
Smooth, monotone in $\tau$, weakly increasing in $\gamma$ above some
threshold.
